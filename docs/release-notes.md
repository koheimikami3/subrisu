# リリースノート

App Store の「このバージョンの新機能」に掲載した文面を、そのまま記録する。
**提出のたびにここへ追記すること。** ストア側の文面は後から遡って読むのが手間なため、
リポジトリ内に控えを持つ。

書き方の決まり:

- 「〜しました。」の短い行を並べる。1 行 1 項目で、1〜3 行に収める
- **内部の仕組みには触れない**。クラス名・パッケージ名は書かず、利用者から見て何が
  変わったかだけを書く。利用者から見える変化が無い版は「内部処理を改善しました。」
- 細かな修正は「軽微な不具合を修正しました。」、見た目の調整は「UIを改善しました。」
  「UIを調整しました。」のようにまとめる
- **初版にはリリースノートを書けない**(App Store Connect に入力欄が無い)。
  1.0.0 が該当し、空欄が正しい
- 見出しは `## <version>`、その下に App Store での公開日を書く。ビルド番号は毎回 `+1` で
  Xcode がアップロード時に繰り上げるため、台帳は持たない
- 1.0.0〜2.7.0 は、2026/09/23 に App Store のバージョン履歴(日本語ストア)から転記した。
  1.1.0〜1.1.4・1.2.0 はリポジトリに対応するコミットが無く、タグも無い
